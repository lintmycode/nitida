WHAT I READ ON THE LIVE SITE

Astro site, Fira Code throughout, lime #C8EE3A over a blue→lime gradient that animates while the sim runs. Nav is inconsistent — Hosting shows on Works but not the homepage, and it is a Cloudways affiliate page rather than a service. Services exist only as tech tags under each project.

WHAT MAKES IT FEEL UNPOLISHED

The 45° gradient animating under everything, mono used for body copy so nothing gets hierarchy, chip-shaped nav buttons that read as debug UI, and a hero with no proposition in it.

THE SYSTEM I'M PROPOSING

Flat brand blue everywhere, cells a half-step lighter so the field reads as texture not flicker. Ink for words, lime for actions only. Fira Code keeps the labels, meta, numbers and nav; a grotesk takes the prose so headlines and paragraphs finally have a scale.
